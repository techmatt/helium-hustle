# Standing rulings

Matt's standing decisions about the game and the project, as they hold now, split by area so
each part has room to grow. A ruling marked **locked** changes only by Matt's decision; one
marked **default** is an executor's pick that stands until Matt overrides it. Engine and docs
rules that bind every item are in [CLAUDE.md](../CLAUDE.md); these pages are the why behind
several of them and the calls that are not code rules.

A new ruling, or a change to one, updates its line in its part in place. A part near the docs
size margin splits again (a new file here, a row below); never trim a ruling to make room.

| Part | What it holds |
|---|---|
| [rulings/game.md](rulings/game.md) | Pillars, speed, tuning and placeholders, Act 1, projects, bonuses, adversaries, retirement, ideology, the day's rate, rules port picks |
| [rulings/programs.md](rulings/programs.md) | Programs: the line template, steps, locked lines, `if`, loadouts, the text editor, readings, `fund` |
| [rulings/engine.md](rulings/engine.md) | Architecture, numbers, rules-history rows, saves |
| [rulings/sim.md](rulings/sim.md) | Sim players, the hands-off measure, the view, the oracle, warning checks, agent code |
| [rulings/ui.md](rulings/ui.md) | Art direction, building art, icons, chip colors, the Cortex mock, screenshots |
