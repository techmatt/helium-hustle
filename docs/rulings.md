# Standing rulings

Matt's standing decisions about the game and the project, as they hold now, split by area so
each part has room to grow. A ruling marked **locked** changes only by Matt's decision; one
marked **default** is an executor's pick that stands until Matt overrides it. Engine and docs
rules that bind every item are in [CLAUDE.md](../CLAUDE.md); these pages are the why behind
several of them and the calls that are not code rules.

A new ruling, or a change to one, updates its line in its part in place. A part near the docs
size margin splits again (a new file here, a row below); never trim a ruling to make room.
