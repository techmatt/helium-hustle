# Rewritten by 113 for rules 38's energy (Data Center upkeep 4, Solar Panel 6): the old
# three-tab loadout (060's L5 line) walled in a run with no titanium and one processor.
# A run starts with one Data Center, so one processor and one step a day, and energy is
# the binding input: everything is one tab, energy consumers stop at what solar carries,
# and no Fabricator or Data Center is built (a second processor buys steps, not energy).
#
# Titanium first (a run starts with none: Buy Titanium until a Smelter makes it), then a
# Solar Panel whenever credits allow (its titanium cost caps how fast), Excavators and a
# Smelter, then one Launch Pad and a Refinery for He-3. `set pads he3 up to` N keeps up
# with `build launch_pad up to` N (a new pad carries nothing). Loading waits for a little
# energy; Sell Cloud Compute spends only the energy above half. Then Science (up to 50 while
# credits allow), the Blueprints (done at once in a run where the Blueprint Archive project
# already granted them) and Process Telemetry, a retirement once the run has bought nothing
# for 300 days (before the player's hand backstop), Daydreaming (`dream_protocols`) and
# dreaming when bored.
seat: 1=all
[1]
if free processors > 0
  assign processors 1 all
if titanium < 10 and credits > 60
  5x buy_titanium
if credits > 20
  build solar_panel
if credits > 50
  build excavator up to 4
  build smelter up to 1
if credits > 150 and titanium > 19
  build launch_pad up to 1
  build refinery up to 1
if titanium > 90% and credits > 100
  build storage_depot
set pads he3 up to 1
if he3 > 10% and energy > 10%
  5x load_pads
launch pads all
if propellant < 20 and credits > 100
  10x buy_propellant
if energy > 50%
  30x cloud_compute
if free land < 5 and credits > 200
  buy land
if science < 50 and credits > 60
  buy_science
if science > 19
  research basic_blueprints
if science > 49
  research advanced_blueprints
  research process_telemetry
if days since a purchase > 299
  retire
if science > 300
  research dream_protocols
if boredom > 50%
  5x dream
